# esp32s31-bt-lib

This repository contains binary libraries for the Bluetooth Low Energy and Bluetooth Classic controllers. It is used as a submodule of the [Espressif IoT Development Framework](https://github.com/espressif/esp-idf) (ESP-IDF).

## Upstream code

These libraries include code derived from the following upstream projects:

1. [Apache Mynewt NimBLE](https://github.com/apache/mynewt-nimble)
